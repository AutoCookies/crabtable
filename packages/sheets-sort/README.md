## Introduction

`@crabtable/sheets-sort` is a sort plugin for CrabTable Sheet.

## Usage

You should use this plugin with the `@crabtable/sheets-sort-ui` package.

### Installation

```shell
# Using npm
npm install @crabtable/sheets-sort

# Using yarn
yarn add @crabtable/sheets-sort
```
