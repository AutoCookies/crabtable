## Introduction

`@crabtable/sheets-note-ui` provides the note/annotation function of CrabTable Sheets.

## Usage

### Installation

```shell
npm install @crabtable/sheets-note-ui
```

or

```shell
yarn add @crabtable/sheets-note-ui
```

### Example

```ts
import { UniverSheetsNotePlugin, INoteMentionDataService} from '@crabtable/sheets-note-ui';

// Register the plugin
univer.registerPlugin(UniverSheetsNotePlugin);
```
