## Introduction

This package provides the basic ability to support find and replace. With other plugins, such as `@crabtable/sheets-find-replace`, you can find and replace text in different types of files at the same time.

## Usage

```ts
import { UniverFindReplacePlugin } from '@crabtable/find-replace';

univer.registerPlugin(UniverFindReplacePlugin);
```

### Installation

```shell
# Using npm
npm install @crabtable/find-replace

# Using yarn
yarn add @crabtable/find-replace
```
