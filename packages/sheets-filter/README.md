## Introduction

`@crabtable/sheets-filter` is a filter plugin for CrabTable Sheet.

## Usage

You should use this plugin with the `@crabtable/sheets-filter-ui` package.

### Installation

```shell
# Using npm
npm install @crabtable/sheets-filter

# Using yarn
yarn add @crabtable/sheets-filter
```
