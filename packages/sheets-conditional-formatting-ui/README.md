## Introduction

`@crabtable/sheets-conditional-formatting-ui` provides full capabilities for CrabTable Sheet conditional formatting, including panel capabilities.

## Usage

### Installation

```shell
# Using npm
npm install @crabtable/sheets-conditional-formatting-ui

# Using yarn
yarn add @crabtable/sheets-conditional-formatting-ui
```

### Register the plugin

```typescript
import { UniverSheetsConditionalFormattingUIPlugin } from '@crabtable/sheets-conditional-formatting-ui';

univer.registerPlugin(UniverSheetsConditionalFormattingUIPlugin);
```
