# @crabtable/telemetry

[![npm version](https://img.shields.io/npm/v/@crabtable/telemetry)](https://npmjs.org/packages/@crabtable/telemetry)
[![license](https://img.shields.io/npm/l/@crabtable/telemetry)](https://img.shields.io/npm/l/@crabtable/telemetry)

## Introduction

This plugin provides interface `ITelemetry` to track telemetry data. The first-party plugins of CrabTable would dependent on this interface. If you want to track telemetry data, you can implement this interface and register it to `Univer`'s injector.

## Usage

### Installation

```shell
npm i @crabtable/telemetry
```
