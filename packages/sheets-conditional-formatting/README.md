## Introduction

`@crabtable/sheets-conditional-formatting` provides CrabTable Sheet with basic capabilities for conditional format rendering computation.

## Usage

### Installation

```shell
# Using npm
npm install @crabtable/sheets-conditional-formatting

# Using yarn
yarn add @crabtable/sheets-conditional-formatting
```

### Register the plugin

```typescript
import { UniverSheetsConditionalFormattingPlugin } from '@crabtable/sheets-conditional-formatting';

univer.registerPlugin(UniverSheetsConditionalFormattingPlugin);
```
