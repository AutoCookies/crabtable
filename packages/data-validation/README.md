## Introduction

> `@crabtable/data-validation` provides CrabTable Sheet with basic capabilities for data validation computation.

## Usage

### Installation

```shell
# Using npm
npm i @crabtable/data-validation

# Using yarn
yarn add @crabtable/data-validation
```

### Register the plugin

```typescript
import { UniverDataValidationPlugin } from '@crabtable/data-validation';

univer.registerPlugin(UniverDataValidationPlugin);
```
