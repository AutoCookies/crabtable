## Introduction

`@crabtable/sheets-thread-comment` provides the comment/annotation function of CrabTable Sheets.

## Usage

### Installation

```shell
# Using npm
npm install @crabtable/sheets-thread-comment

# Using yarn
yarn add @crabtable/sheets-thread-comment
```

### Register the plugin

```typescript
import { UniverDocsThreadCommentUIPlugin } from '@crabtable/docs-thread-comment-ui';

univer.registerPlugin(UniverDocsThreadCommentUIPlugin);
```
