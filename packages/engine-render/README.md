## Introduction

The `@crabtable/engine-render` provides the ability to render CrabTable documents on a canvas element, including the capability to draw graphical elements, handle cursor interactions, and process scrolling and zooming.

The rendering layer for various document types is extended based on the foundational infrastructure provided by `@crabtable/engine-render`.

## Usage

### Installation

```shell
# Using npm
npm install @crabtable/engine-render

# Using yarn
yarn add @crabtable/engine-render
```
