# @crabtable/docs-hyper-link-ui

## Introduction

`@crabtable/docs-hyper-link-ui` provides the link function of CrabTable Docs.

## Usage

### Installation

```shell
# Using npm
npm install @crabtable/docs-hyper-link-ui

# Using yarn
yarn add @crabtable/docs-hyper-link-ui
```

### Register the plugin

```typescript
import { UniverDocsHyperLinkUIPlugin} from '@crabtable/docs-hyper-link-ui';

univer.registerPlugin(UniverDocsHyperLinkUIPlugin);
```
