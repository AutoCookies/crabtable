This plugin adds a crosshair highlight to the CrabTable Sheet.

## Usage

### Installation

```shell
# Using npm
npm i @crabtable/sheets-crosshair-highlight

# Using yarn
yarn add @crabtable/sheets-crosshair-highlight
```
